# Pixel art quality rules
Read `docs/ART_PIPELINE.md` and `docs/ART_CONTRACT.json`. Use original character concepts only. Standardize silhouette, hair, face, outfit, palette and light direction across all poses. One animation frame per image, fixed RGBA canvas and common foot anchor. Avoid anti-aliasing. Inspect contact sheet and 2x animation before accepting. Code-generated geometry is the zero-cost baseline; image models are optional and cannot be assumed to produce precise pixels. Never import branded anime character art.
